This copy of Hajri isn't connected to a Google Sheet yet.

To connect it:

  1. Create a Google Sheet in your Drive.
  2. Extensions → Apps Script, paste in the hajri-backend.gs code.
  3. Deploy → New deployment → Web app → Execute as Me, access Anyone.
  4. Copy the URL ending in /exec.
  5. Open this HTML file in a text editor, find APPS_SCRIPT_URL near the top of the script, and paste your URL in.
  6. Re-upload the file to your host (GitHub Pages / Netlify / Firebase Hosting) and reload this page.

Once connected, everyone who opens this page's link will see and edit the same data, stored in your Sheet.
